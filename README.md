# Java Calculator

A calculator application developed using Java and Maven.

## Overview

This project is a Java calculator application developed as a programming project.

## Technologies Used

* Java
* Apache Maven
* NetBeans IDE

## Project Structure

* `src/` — Contains the Java source code.
* `pom.xml` — Contains the Maven project configuration.

## How to Run

1. Clone or download the repository.
2. Open the project in Apache NetBeans IDE as a Maven project.
3. Build the project and run its main class.
